# BtechPrepApp

An Android application designed for engineering students to streamline their academic preparation.

## Features
- Notes management
- Subject organization
- Syllabus tracking
- Study resources
- Clean Android UI

## Tech Stack
- Kotlin
- Jetpack Compose
- Android Studio

## Future Improvements

- AI-powered study planner
